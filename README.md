# Matthew Lacson Portfolio

Personal portfolio website for showcasing my software development, UI/UX, and project work.

This site is built with HTML and CSS and hosted through GitHub Pages.

## Live Site

Visit the portfolio here:

```text
https://mattlacson.github.io
```

## Overview

This portfolio highlights selected projects, case studies, and technical work. It includes projects related to UI/UX design, web development, Python/Flask development, and C++ programming.

The goal of this site is to present my work in a clean, simple, and organized way for recruiters, employers, and anyone interested in my projects.

## Featured Projects

### Overwatch 2 UI/UX Case Study

A UI/UX case study focused on improving the Overwatch 2 new-player experience. The project explores user flow, interface clarity, onboarding issues, and design improvements.

### Squid Game Text-Based Simulation

A C++ text-based game simulation inspired by Squid Game. The project focuses on game logic, state management, decision-making systems, and object-oriented programming.

### League Improvement Coach Bot

A Flask web app that gives League of Legends ADC players personalized improvement plans based on their rank, champion pool, focus champion, and gameplay struggles.

The project includes champion-specific advice, post-game review questions, and “Next 10 Games” improvement plans.
